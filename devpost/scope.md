# Hephaestus

An installable coding-agent skill for auditing and repairing existing frontends.

## The Unique Kernel
Apply the learner's 30-rule anti-slop policy while preserving working behavior, approved brand choices and genuine business facts. Show actual evidence for each repair.

## Who It's For
A builder using Codex, Claude Code or another compatible agent who already has a frontend and wants a focused, explainable repair.

## The Core Loop
Install the skill, select a frontend and task, inspect evidence, make a scoped repair, and review the diff and observed checks. Reuse the skill when another interface needs attention.

## Inspiration & Identity
The learner's [architecture](../docs/arc.md) and [product requirements](../docs/pro.md) define the frontend rules. [Taste Skill](https://github.com/leonxlnx/taste-skill) contributes attributed composition and critique guidance. Hephaestus is a skill; it has no hosted product UI.

## Why This Matters to the Learner
The learner identified generic AI websites and repeated bad defaults as the problem. No personal learning outcome has been inferred.

## What "Working" Looks Like
A fresh agent uses the skill on an isolated, runnable project-list fixture. The repaired screen shows honest pending, success, empty and failure states, supports retry, preserves the endpoint and approved content, and fits 390/768/1440px. Reviewers can inspect before/after source, captures and actual check results.

## The POC Boundary
Frontend skill package, one deterministic local repair fixture, real browser verification, concise learning documents, technical run instructions and meaningful commits. This extends an existing package; it does not pretend planning preceded its first implementation.

## Later
Backend repairs, broader React/Next.js repair evaluations, other agent hosts and a controlled comparison of visual quality.

## Explicitly Cut
Hosted dashboard, accounts, database and upload service: unnecessary for proving an installable skill. Course interviews are development guidance, not a runtime dependency bundled into Hephaestus.

This draft records decisions already supplied and the current authorized work. It does not claim a completed Devpost interview or document review.
