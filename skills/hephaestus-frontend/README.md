# Hephaestus: Frontend Fixer

**Stop AI slop before it ships.**

Audit and repair existing frontends with the Hephaestus 30-rule policy, bundled Taste direction tools, source lint and browser inspection. Select this for UI, accessibility, responsive layout and frontend state defects.

Run `$hephaestus-frontend` in Codex or `/hephaestus-frontend` in Claude Code. This entry selects the frontend workflow directly. Audit-only work preserves source; repairs require actual verification. Keep secret keys out of chat.
