# Hephaestus

**Stop AI slop before it ships.**

Audit and repair existing frontend and backend code inside your coding agent, with scoped changes and evidence of what works.

- **Frontend Fixer** improves UI, accessibility, responsive layouts and request states using the 30-rule frontend policy.
- **Backend Fixer** repairs server code with seven security guardrails covering secrets, authentication, validation, database access, dependencies, rate limits and security analysis.

Choose **Frontend Fixer** or **Backend Fixer**, or select `$hephaestus-frontend` or `$hephaestus-backend` directly in Codex. Claude Code uses `/hephaestus-frontend` or `/hephaestus-backend`. Install all three skills to see both direct choices in the picker; the router still accepts `$hephaestus frontend` and `$hephaestus backend`.

Audit-only work leaves project code unchanged. Repairs preserve your data and contracts; missing checks stay unverified. Keep secret keys out of chat.
