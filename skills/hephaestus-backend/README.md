# Hephaestus: Backend Fixer

**Stop AI slop before it ships.**

Audit and repair existing backend code with Hephaestus security guardrails for secrets, authentication, validation, data access, dependencies, rate limits and security analysis.

Run `$hephaestus-backend` in Codex or `/hephaestus-backend` in Claude Code. This entry selects the backend workflow directly. Audit-only work preserves source; repairs require actual verification. Keep secret keys out of chat.
